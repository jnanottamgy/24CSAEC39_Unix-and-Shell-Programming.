# 24CSAEC39 — UNIX and Shell Programming

Coursework and lab programs for **UNIX Shell Programming** (3rd semester, 1:0:0, 15L).

## Contents

- [`syllabus/unix-shell-programming.md`](syllabus/unix-shell-programming.md) — the course syllabus, all five units
- `unit-01/` … `unit-05/` — lab programs, added per unit

## Units at a glance

| Unit | Topic | Lab component |
|-----:|-------|---------------|
| I | Introduction to UNIX — architecture, file system, `vi`, file permissions, basic commands | Basic commands on the terminal |
| II | Shells — UNIX session, process / disk / networking / text-processing / backup utilities | Process, disk and text-processing commands |
| III | Standard streams — redirection, pipes, `tee`, quotes, command substitution, aliases, variables | Shell environment customisation and redirection |
| IV | Filters — `cat`, `head`/`tail`, `cut`/`paste`, `sort`, `tr`, `uniq`, `grep` | Filter commands |
| V | Shell scripts — `read`, arguments, exit status, `if`/`case`/`test`, `expr`, `while`/`for`, `set`/`shift` | Shell script programs |

**Pre-requisite:** C Programming
